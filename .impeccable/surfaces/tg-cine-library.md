# 渐进片库、作品整理与文件详情

2026-10-16 观看导航增量：作品详情显示实际文件版本观看状态、该作品最近未完成文件的续看入口。下一集按真实季集查询并列出该集可用文件，跨页保留多版本，由用户选择，不自动连播、不猜缺集；该选择页不显示批量整理提示。文件身份、观看记录及账号范围不合并。验收见 [日常使用闭环](../../docs/daily-use-stage.md)。

Mode: Operate. 沿用已确认的 ForUI neutral touch、Inter/中文回退、Lucide、明暗主题及既有四项响应式导航，不另建视觉世界。原生授权来源支持历史分页、暂停/恢复、原始条目搜索、源消息追溯及所选文件播放；iOS/Android 共用逻辑。

## Direction contract

THESIS: 已保存的真实文件可找到；每批保存后即可浏览，用户知道哪些来源仍在整理，并可暂停后继续。

OWN-WORLD: ForUI 默认组件与主题、48dp 操作、中文标签、原文件信息优先；没有海报时使用文件列表，不伪造海报或可播放状态。

STORY: 保存来源 → 在片库开始分批导入 → 已保存条目立即可见 → 搜索文件名、说明或来源 → 选择文件查看大小、已知时长和原说明 → 复制源消息链接回 Telegram 追溯。后台暂停，前台由用户继续；切换账号清空当前显示。详情文件名下提供「播放此文件」，再次打开恢复本机进度；既有开发播放器保留。

FIRST VIEWPORT: 有内容时首先展示搜索、导入来源入口、管理来源和分类筛选；无搜索词且选择全部时显示最近五条有进度、未完成的续看记录，再展示真实文件列表。空库展开来源进度与开始操作。搜索、操作、筛选、续看、来源控制、错误与重试和文件分页处于同一条可滚动列表，避免小屏大字号的嵌套滚动陷阱。

FORM: 文件行优先显示本机归整片名并另列原文件名，未归整时以原文件名为标题；标题两行省略，原文件名辅助行与来源一行省略，大小和时长可换行，详情可读完整名称。宽度达到 860dp 且字号比例小于 1.6 时并排预览，其他窗口打开独立详情页。搜索跨导航保留；加载、失败、无结果、暂停、完成各有中文反馈。导入按保存条目计数，不使用虚构百分比；逐来源手动检查新消息，可暂停后继续。播放主按钮最小 48dp，置于文件名下方；本机保守文件名识别支持电影、电视剧与待整理，详情提供人工修正与恢复识别，明确显示识别来源。没有在线影视资料、海报或跨设备同步。

FINISH: Flutter 组件矩阵、原生渲染截图、独立 Impeccable 审查与文档记录；不以浏览器 detector 判断 Flutter 布局，不把 Windows 平台变体称为移动真机截图。截图仅使用标注的设计数据。

## 验收边界

原文件片库、历史分页、暂停/继续、搜索、详情与源消息链接已接线；片库播放与本机位置恢复已接线；观看记录、首页续看、手动新消息检查及本机文件名归整已接线。完成态仅表示历史扫描结束；新消息需主动检查，在线影视资料仍未接入。

全量 199 项 Flutter 测试、静态分析及普通 Android Debug 构建通过。Android NE2210 真机与 Windows 的协议替身 → 真实加密 SQLite → Flutter 导入、去重及重开恢复通过，不能代替真实移动 Telegram 导入。真实 Windows 授权来源两次独立进程批次累计保存 25 个元数据条目，检查点继续推进，历史未结束；输出只保留数量，不捕获私有片库画面，不下载视频。

2026-10-15 增量：Android 已交付 TDLib，真实应用重开自动恢复授权、已选来源和 25 条媒体。私聊消息不支持普通源链接，按 TDLib 能力明确提示，不伪造复制成功。全量 238 项 Flutter、2 项 Windows 集成测试通过，64 张新设计数据截图含 16 张能力提示；代表性画面人工检查通过，保持 ForUI、48dp 操作与 liveRegion。iOS 模板远程构建已通过，带 TDLib 的构建与运行尚在独立 CI 验证，真实账号及真机未验收。本轮不恢复播放排查。

## 日常片库方向增量（2026-10-16）

保持 Operate 与既有 ForUI neutral touch。片库搜索、操作、分类筛选、最近五条续看、来源进度与文件均在同一滚动区；小屏大字体不固定一组高占位控件。宽屏 860dp 及字号比例小于 1.6 保留左右列表/详情，记录页用单列时间顺序和真实播放进度，来源失效或文件版本被替换时明确说明并禁用播放。记录页清空确认、错误、重试和分页均随列表滚动，两页重试与分页操作至少 48dp。删除单条不触碰原媒体，清空记录先就地确认，切换账号使确认失效。

详情以原文件名和播放入口开头，再展示识别片名、类型、年份、季集与识别来源。修正表单就地展开，错误与重试留在表单；手动值不被导入覆盖，可显式恢复文件名识别。所有新增操作至少 48dp，控件用 Wrap，表单可随键盘滚动。没有海报或在线识别；作品可关联多个原始条目，但原始消息与文件身份不合并。

## 作品片库方向增量（2026-10-16）

保持 Operate、ForUI neutral touch 和原文件片库。「片库 → 作品片库」进入作品列表；可搜索作品、打开作品查看实际季集与当前文件，也可切换「整理文件」搜索并筛选待整理。作品、成员文件和整理文件均按 50 条分页；同一季集多个当前文件分别显示原文件名、来源、大小，再进入文件详情。只展示实际已有集数，不推测总集数或缺失集。

作品及文件列表最大 1080dp，批量整理表单最大 720dp，均居中单列滚动。最多选择 100 个文件；选择、取消、加载更多与归组操作使用最小 48dp 的 ForUI outline 按钮，选中状态使用 selected，操作通过 Wrap 适应窄屏与大字号，返回为 48×48dp。文件名可换行，不把当前页当作整部作品。

批量流程为选择文件 → 加入已有作品或新建独立作品 → 确认共同片名、类型、年份及逐文件季集 → 预览 → 确认保存。独立作品允许拆分同名条目；预览列出具体文件、来源和目标季集，可返回编辑。保存失败保留输入供重试，保存中禁用相关操作；校验、保存状态和错误使用 liveRegion。「撤销选中归组」须就地确认，仅解除归属，保留原文件、人工信息与观看记录，重复导入也不恢复已撤销的归属。

作品关联已存在，但原始消息、实际文件版本及观看进度身份不合并。仅列已选来源的当前文件；人工归组不被重复导入覆盖。单文件修改共同片名、年份或类型时退出原人工组，仅改季集仍保留归属。账号或来源范围变化使旧页面和提交失效：旧作品标题切回通用标题，正文仅显示不可用，不能残留上一账号的作品名。

本轮实现与验证范围见 [作品阶段](../../docs/works-stage.md)，设计数据原生截图位于 `.impeccable/review/works/`；历史验收段落保持原记录。Windows 元数据检查未发现新消息，Android/iOS 本轮移动真机仍待验收，不新增播放或部署结论。
