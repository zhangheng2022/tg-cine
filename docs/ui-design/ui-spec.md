# TG Cine UI 设计规范

状态：静态高保真设计，2026-10-12。用户确认只先看完整页面与规范，不修改 Flutter 界面。本稿采用 Impeccable Operate 模式，继承已选“浏览片库＋详情预览”结构及 ForUI neutral 主题；设计数据均为虚构。

## 交付与阅读

- 打开 `index.html` 查看页面总览；点击图稿可查看可滚动静态画面。`exports/` 为可直接分享的 JPG：23 个页面／状态各有手机与宽屏浅色主稿，共 46 张，另有 15 张主题、尺寸和大字补充稿，共 61 张。主稿命名为 `{phone|wide}-{page}-light.jpg`，补充稿可从总览的“全部补充检查稿”直接打开。
- `screen.html?page=library&theme=dark` 展示对应静态页面；`full` 展开长页面，`text=large` 为大字示意。所有应用控件无业务行为，只有总览链接用于阅读。
- 在仓库根目录执行 `python -m http.server 55823 --bind 127.0.0.1 --directory docs/ui-design`，访问本地 `/index.html`。也可直接打开导出图，不依赖服务。
- 根 `DESIGN.md` 继续记录已实现的三页初始化界面。本文件与设计稿描述下一阶段目标，不表示应用已接入 Telegram、播放或中转。

## 视觉体系

延续 ForUI 0.27.4 neutral light/dark touch：浅色背景 `#FFFFFF`、前景 `#0A0A0A`、主操作 `#171717`、边框 `#E5E5E5`；深色背景 `#0A0A0A`、前景 `#FAFAFA`、卡片 `#171717`、主操作 `#E5E5E5`。设计稿采用浅色辅助文字 `#666666`，确保小号正文对比度；深色辅助文字为 `#A1A1A1`。警告和错误通过颜色、图标与文字共同表达，不能仅依赖颜色。

界面使用随 ForUI 分发的 Inter，中文由平台字体回退。本稿在 Windows 使用 Microsoft YaHei；Flutter 中按系统字体缩放，不照搬浏览器字形和行高。字体许可位于 `assets/Inter-OFL.txt`。图标采用与 Lucide 一致的描边几何；落地使用 ForUI 的 `FLucideIcons`。

本节描述静态稿实际使用的视觉值及后续落地目标。HTML 中尺寸使用 CSS px，文中的 dp 与字号基准用于指导 Flutter 实现，尚未经过原生尺寸映射验证。浅色说明色 `#666666` 与正文 14sp 目标没有替换根 `DESIGN.md` 记录的当前 ForUI 运行时 token。

| 角色 | 设计基准 | 用途 |
| --- | --- | --- |
| 页面标题 | 手机 24、宽屏 28，650 字重 | 目的地、页面名称 |
| 影片详情标题 | 手机 25、宽屏 34 | 选中影片，不用于每个列表项 |
| 区块标题 | 18–19，650 字重 | 继续观看、可用版本、剧集 |
| 正文 | 14，行高 1.6–1.85 | 信息、简介、状态 |
| 说明 | 12–13；手机短辅助信息可 11 | 年份、来源、诊断等 |
| 操作 | 13–14，600 字重 | 最小 48dp 点击范围 |

间距使用 4、8、12、16、20、24、32、40；手机页边距 20dp（320dp 为 16dp），宽屏内容边距 32dp。按钮、输入、分组圆角为 10dp，海报 9dp。以边框与浅底区分层级，不增加装饰阴影、渐变或玻璃效果。素材中的色彩不进入控件主题。

## 响应式布局

| 可用宽度 | 构图 |
| --- | --- |
| <600dp | 四项底部导航；两列海报；点击进入独立详情。长页滚动，重要动作至少 48dp |
| 600–1023dp | 88dp 窄侧栏；扩大网格；不强挤详情预览 |
| ≥1024dp | 196dp 侧栏＋片库＋328dp 详情预览；各区独立滚动 |

大字体减少网格密度、允许按钮与状态换行；静态稿的 `text=large` 将正文基准从 14px 调到 18.2px，并调整部分组件字号和排列，不等同于每个字号统一放大 1.3 倍。中屏静态稿使用图标窄侧栏；Flutter 落地需保留导航的辅助功能名称，并提供可发现的文字说明。缩放过大时按内容最小宽度关闭预览、保留可读导航标签属于落地要求，不能视为静态稿已有的动态能力。断点只是落地起点，须在 Flutter 按实际布局约束确认。保留系统安全区域、键盘避让、平台返回与可见焦点；不得依赖悬停提供唯一操作。

## 页面与交互约定

23 个静态页面在总览按片库、观看、整理、启用、支持排列。顶层四目的地为片库、记录、来源、设置；详情、选集与播放器进入内容层级。首页焦点是继续观看，其次是可浏览海报；宽屏单击条目仅更新预览，播放需要明确按钮。

详情展示实际可用版本与来源；资料集数不能变成虚假播放入口。主操作使用本机对应版本进度；切换版本先选择起点。来源与原消息均可追溯，人工纠正不被后续导入覆盖。影片标题是可读文字，不能烘焙进海报。

播放器为沉浸式深底，保留影片画幅；此稿的竖向海报裁片只是静态场景占位，实际播放必须使用原视频比例。手机静态稿把播放／暂停、快退、音量、全屏放在第一行，字幕与选集放在第二行，图标操作保留 48×48 范围。控件经操作、键盘聚焦或辅助功能显示属于落地要求；48dp 操作，字幕和音轨只在实际存在时出现。剧集结束提供下一集按钮，默认不自动跳集。退出保存实际媒体版本的本机位置并返回浏览上下文。

首次启用说明非官方身份与合法媒体 → Telegram 登录 → 用户选来源 → 分批导入。验证码长度、发送渠道、冷却时间和两步验证由实际响应决定，本稿中的号码与倒计时不可当作协议。不开独立账号、不设邀请码、不要求填写 Worker 地址或令牌。

默认服务不可用仍可浏览本机索引与历史，播放按钮在实现时切换为明确的不可用说明或恢复操作。导入计数未知时不显示百分比；部分失败单独重试。无来源、来源无媒体、无搜索结果、匹配不确定、账号失效、请求受限均有独立状态。

设置覆盖账号断开、默认服务状态、本机清理、资料补全、主题、隐私、隐藏、反馈与联系。移除来源仅移除本机关联，不删除 Telegram 原消息；不可逆的本机清理展示范围并确认。反馈先展示必要信息，默认不上传私密聊天内容。隐私政策及联系入口是页面结构，正式文本与 URL 需与运营事实一致。

频道来源预留 Telegram 官方赞助消息区域，实施时使用官方响应与规定交互；示意内容不能当作真实广告或承诺无广告。

## 组件状态与落地映射

| 设计组件 | ForUI 落地候选 | 必须保留的状态 |
| --- | --- | --- |
| 主操作／次操作 | FButton | 默认、按下、焦点、禁用、等待 |
| 顶部、底部导航 | FHeader、FBottomNavigationBar | 当前目的地、键盘焦点、安全区域 |
| 搜索与登录字段 | FTextField | 空、输入、焦点、错误、禁用 |
| 筛选、版本、选季 | FSelect / FPopover、选择控件 | 选中、展开、无选项、不可用 |
| 设置与来源行 | FTileGroup、FTile | 默认、禁用、说明、操作 |
| 开关、来源多选 | FSwitch、FCheckbox | 开／关、选中、禁用、聚焦 |
| 提示与确认 | ForUI 提示、对话框 | 错误原因、恢复动作、清理范围 |
| 海报与续看 | 项目共享组件＋主题 token | 缩略图回退、选中、焦点、实际进度 |

以上是设计映射，具体构造函数以落地时安装版本为准。截图中的控件无事件，不代表组件实现、键盘导航或辅助功能已验收。动效只服务于选择更新与播放控件显隐：150–250ms，减少动态效果时直接切换。

## 素材与验收边界

六部影片、简介、来源、账号和计数均为原创设计数据。`fictional-posters.png` 为 AI 生成的六联画，用 CSS 精确分区展示；完整提示词在旁置文本及 PNG 元数据中。用于评审，不自动成为商店宣传或真实内容授权材料。

静态检查覆盖 390dp 手机、1440dp 宽屏，补充 320dp、800dp、1280dp、深色与 1.3 倍文字。长页导出展开正文，不模拟真实手机屏幕总高度。截图和规范只能证明视觉及文案，不能证明 Flutter 运行、网络可达、媒体解码、登录、数据隔离或 App Store 审核通过。

`render-check.json` 保存 50 条初检记录与 4 条重点复查记录；其字段和覆盖范围见 [审查记录](review.md)。61 张导出图的视觉评审与这些尺寸记录是不同证据，不能据此声称全部页面、主题和字号组合都完成自动检测。

实施时仍须运行 Flutter 静态分析、组件测试与实际渲染，并验证系统返回、字体缩放、读屏、键盘与横屏。默认服务当前 `501`，本次不修改、不部署 Worker。
