# TG Cine 产品轮廓

目标：连接 Telegram 的个人影视库与播放器，专注电影、电视剧和连续观看。

本文件描述产品方向，未勾选的内容尚未实现。当前可运行版本为命令行播放与测速原型。

## 已有基础

- [x] 本机 Telegram 账号登录，验证码与二次验证密码在本机输入。
- [x] 选择可访问会话及最近视频。
- [x] MTProto 分片读取、本机 HTTP Range 播放接口。
- [x] Cloudflare Worker WSS 中继、固定 Telegram 目标及中继鉴权。
- [x] 分片测速、有限重连、文件引用刷新及基础自动化测试。

## 首版产品

- [ ] Windows 桌面界面与内嵌播放内核。
- [ ] 本机会话加密保存、退出及撤销登录流程。
- [ ] 用户主动选择内容来源，分页同步历史视频。
- [ ] 影视库：电影、电视剧、搜索与收藏。
- [ ] 详情：电影版本选择、电视剧按作品 / 季 / 集整理。
- [ ] 根据文件名与消息文字辅助识别，允许手动改名、调整集数和合并作品。
- [ ] 首页：继续观看、最近新增、正在追的剧。
- [ ] 播放器：续播、字幕、音轨、倍速、全屏、上一集 / 下一集及自动连播。
- [ ] 消息删除、访问权限变化、内容保护及频道赞助消息处理。

## 页面

| 页面 | 核心用途 |
| --- | --- |
| 首页 | 继续观看、最近新增、追剧入口 |
| 影视库 | 搜索、筛选、收藏电影和电视剧 |
| 影视详情 | 查看作品、选择版本或剧集 |
| 播放器 | 播放、拖动、字幕音轨、连续观看 |
| 内容来源 | 添加会话、同步状态、整理识别错误 |

## 发布前验收

- [ ] 真实影片连续播放 1–2 小时，记录首帧、卡顿和内存。
- [ ] 随机拖动、切片切集、断网恢复、睡眠唤醒与会话失效。
- [ ] H.264、HEVC 10-bit、AV1、MKV、字幕及多音轨样本。
- [ ] 不同网络、运营商与时段的首次连接和持续播放。
- [ ] 统一分片调度、重复请求合并与旧播放位置取消。
- [ ] 若提供公共中继：独立用户鉴权、凭证撤销、配额及容量测试。

首版暂不纳入公共资源聚合、社交评论、云端转码和跨设备同步。
